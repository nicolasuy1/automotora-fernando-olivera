# Oferta Comercial - Presencia Digital Premium

## Propuesta

Crear una presencia digital completa para Fernando Olivera Vehiculos, empezando por una web premium con catalogo y preparada para crecer hacia CRM, automatizacion y captacion local.

La web no sera solamente una vidriera. Sera una maquina de confianza y conversion, conectada a WhatsApp y pensada para que cada visitante entienda rapido que puede consultar, financiar y llevarse un vehiculo.

## Entregable Inicial

- Homepage premium.
- Catalogo de vehiculos por categoria.
- Fichas individuales de vehiculos.
- Pagina de financiacion, entrega y permuta.
- Pagina de clientes, entregas y testimonios.
- Pagina de contacto con WhatsApp, ubicacion, horarios y mapa.
- Arquitectura preparada para panel privado futuro.

## Valor Para el Cliente

- Mas confianza en segundos.
- Mejor percepcion de marca.
- Menos dependencia exclusiva de Instagram.
- Consultas mas ordenadas por WhatsApp.
- Mejor posicionamiento en Google local.
- Base lista para automatizar respuestas y seguimiento.
- Material comercial para campanias pagas.

## Argumento de Venta

Instagram muestra movimiento. La web convierte ese movimiento en confianza.

Una persona puede descubrir un vehiculo en redes, entrar a la web, ver categorias, entender la financiacion, confirmar ubicacion, leer testimonios y escribir por WhatsApp con una consulta mas decidida.

## Modulos Comerciales

### Modulo 1 - Web Premium

Diseño, desarrollo y publicacion de una web moderna, responsive y orientada a conversion.

### Modulo 2 - Catalogo

Estructura para mostrar autos, motos, utilitarios, SUV y oportunidades destacadas. El catalogo debe funcionar aunque el stock cambie rapido.

### Modulo 3 - Google Business Profile

Optimizacion de perfil, fotos, descripcion, categorias, publicaciones y estrategia de reviews.

### Modulo 4 - SEO Local

Contenido y estructura para posicionar busquedas como "automotora en Ciudad del Plata", "autos financiados San Jose", "motos financiadas Uruguay".

### Modulo 5 - WhatsApp Comercial

Botones y mensajes prearmados segun seccion: catalogo, financiacion, permuta, contacto y ficha de vehiculo.

### Modulo 6 - Automatizacion Futura

CRM, formularios, seguimiento de consultas, recordatorios, carga de stock y dashboard privado.

## Resultado Buscado

El cliente debe sentir que no esta comprando una pagina web. Esta comprando una presencia digital moderna para vender mas, responder mejor y posicionarse por encima de automotoras competidoras.
