# Roadmap

## Fase 0 - Organizacion y Estrategia

Objetivo: ordenar el proyecto para que la demo tenga narrativa comercial, direccion visual y arquitectura escalable.

Entregables:

- Brief del cliente.
- Oferta comercial.
- Direccion visual.
- Arquitectura tecnica.
- Roadmap.
- Prompts maestros.
- Estructura de carpetas.

## Fase 1 - Demo Premium Comercial

Objetivo: crear una experiencia visual impactante para presentar al cliente y cerrar la venta.

Entregables:

- Homepage cinematografica.
- Hero con auto/video protagonista.
- Storytelling de scroll.
- Catalogo generico por categorias.
- Seccion de financiacion.
- Testimonios y confianza.
- CTAs a WhatsApp.
- Responsive mobile-first.

## Fase 2 - Demo Navegable En Vite

Objetivo: mantener velocidad de presentacion y convertir la demo en una experiencia navegable sin migrar todavia.

Entregables:

- Rutas `/`, `/catalogo`, `/catalogo/[slug]`, `/financiacion`, `/clientes`, `/contacto`.
- Componentes modulares.
- Datos mock separados.
- WhatsApp por vehiculo.
- Base visual lista para presentar.

## Fase 3 - Catalogo Real

Objetivo: convertir el catalogo en una herramienta comercial usable.

Entregables:

- Fichas individuales.
- Filtros por categoria, precio, anio y financiacion.
- Estados de stock.
- CTAs por vehiculo.
- Mensajes prearmados de WhatsApp por unidad.
- Carga inicial manual desde data local.

## Fase 3.5 - Evaluacion Productiva

Objetivo: decidir si conviene migrar a Next.js, TypeScript y backend segun cierre comercial, presupuesto y necesidades reales.

Opciones:

- Mantener Vite si la web sera mayormente estatica.
- Migrar a Next.js si se priorizan SEO avanzado, rutas server-side y crecimiento tecnico.
- Integrar Supabase si el cliente necesita cargar stock y leads desde panel.

## Fase 4 - SEO Local y Google Business

Objetivo: posicionar a Fernando Olivera Vehiculos en busquedas locales.

Entregables:

- Copy SEO local.
- Schema markup.
- Paginas optimizadas.
- Google Business Profile optimizado.
- Estrategia de reviews.
- Links rastreables a WhatsApp.

## Fase 5 - Automatizacion y CRM

Objetivo: ordenar consultas y mejorar seguimiento comercial.

Entregables:

- Supabase para vehiculos y leads.
- Panel `/admin`.
- Gestion de stock.
- Registro de consultas.
- Estados de lead.
- Integracion futura con WhatsApp/API o CRM externo.

## Fase 6 - Performance, Medicion y Ads

Objetivo: convertir la web en una maquina medible de ventas.

Entregables:

- Analytics.
- Eventos de CTA.
- Pixel de Meta.
- Conversiones de WhatsApp.
- Landing para campanias.
- Optimizacion de velocidad.
- Iteracion segun datos reales.

## Prioridad Comercial

La primera version no debe intentar resolver todo el negocio. Debe vender la vision:

Fernando Olivera Vehiculos puede pasar de depender solo de Instagram a tener una presencia digital premium, confiable, medible y preparada para escalar.
